# Security Policy

## Supported Versions

Security fixes are provided for the latest version available on the `main` branch. Older releases may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

If you discover a potential vulnerability in Nightcheck, contact the repository owner privately through the contact options available on their GitHub profile. Include:

- A clear description of the issue and its potential impact.
- The affected version, commit, or component.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation, if known.

Please allow reasonable time for the issue to be reviewed and addressed before publicly disclosing it.

## Scope and Responsible Use

Nightcheck is intended for security checks on systems you own or are explicitly authorized to assess. Do not use it to test systems without permission.
